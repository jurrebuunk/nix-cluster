*[VLAN]: Virtual LAN: a separate network on shared cables, identified by a tag number
*[VIP]: Virtual IP: a floating address that moves to a healthy machine
*[VRRP]: Virtual Router Redundancy Protocol, used by Keepalived to decide who holds a VIP
*[OSD]: Object Storage Daemon: the Ceph process that stores data on one disk
*[RGW]: RADOS Gateway: Ceph's S3-compatible object storage service
*[RBD]: RADOS Block Device: a Ceph-backed virtual disk
*[CephFS]: Ceph's shared POSIX file system
*[MDS]: Ceph Metadata Server, needed for CephFS
*[PG]: Placement group: the unit Ceph uses to distribute and recover data
*[CRUSH]: Ceph's placement algorithm that decides where copies go
*[WARP]: Cloudflare's device client (Cloudflare One) that routes traffic into Zero Trust
*[DNS-01]: ACME challenge that proves domain ownership with a DNS TXT record
*[ACME]: The protocol Let's Encrypt uses to issue certificates
*[TAP]: A virtual network interface that connects a VM to a host bridge
*[NIC]: Network interface card
*[etcd]: The key-value store that holds Kubernetes state on the k3s servers
*[SMART]: Self-Monitoring, Analysis and Reporting Technology: a disk's health data
*[agenix]: Tool that stores secrets encrypted with age to SSH keys
*[DHCP]: Dynamic Host Configuration Protocol: hands out addresses automatically
*[NAT]: Network address translation
*[LACP]: Link Aggregation Control Protocol: bundles several cables into one link
*[SNI]: Server Name Indication: the hostname a TLS client asks for
